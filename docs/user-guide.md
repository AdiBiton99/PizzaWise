# PizzaWise User Guide

PizzaWise helps you build one pizza, pick a search area, and see which nearby shops can make it. Use **Build my pizza** on Home, or follow the steps **Build → Location → Compare → Checkout → Confirmation**.

## Build a Pizza

Open **Build Pizza**. The **Pizza Builder** walks you through choices in order:

1. **Size**
2. **Crust**
3. **Sauce**
4. **Toppings** (optional — you can continue with none)

Use **Continue** after each step. **Back** returns to the previous step so you can change your choices. **Your pizza** shows the current selection.

When you reach **Ready**, choose **Continue to location**.

## Choose a Location

On **Where should we search?** pick a place and a **Search radius**. You can change them independently: **Change location** only updates the place; **Search radius** stays available without searching again.

**Use my location** asks the browser for your current spot. Allow location access if prompted.

Or type a **City or address** and press **Search**, then pick a result.

**Search radius** options: **5 km**, **10 km**, **15 km**, **25 km**, **50 km**, and **All**. **All** includes every listed pizzeria, regardless of distance.

Then choose **Continue to compare**. You can **Change location**, change the radius, or **Edit pizza** later if you need to.

## Compare Pizzerias

On **Compare nearby pizzas**, choose **What's most important to you?** then press **Compare**.

| Choice | Emphasis |
| --- | --- |
| **Best overall** | A mix of price, distance, and delivery time |
| **Lowest price** | Price |
| **Closest** | Distance |
| **Fastest** | ETA (estimated delivery time) |

Results are a ranked list. The first shop is marked **Top match**. Each row shows **Price**, **Distance**, and **ETA**.

If some shops could not be checked, you will see: *Some nearby pizzerias could not be checked. Try Compare again.* Ranked shops are still usable. **Retry comparison** if the whole compare fails.

If nothing matches, try a larger radius (including **All**) or **Edit pizza**.

## Place an Order

From a result, choose **Order from [shop name]**. If you are not signed in, use **Log in to order** first (or **Sign up**).

**Checkout** is titled **Order from [shop name]**. PizzaWise re-checks the live menu and price before placing. Saved **Phone** and **Default delivery address** from Account prefill the form; you can edit them for this order without changing your profile.

1. **Fulfillment:** **Pickup** or **Delivery**
2. **Phone** — required
3. **Delivery address** — required only for **Delivery**
4. **Place order** — stays disabled until the required fields are filled

You then see **Order confirmation** with status **placed**, plus the pizzeria, pizza, total, fulfillment, phone, and address when you chose delivery. Open **View order history** or **Build another pizza**. You can also **Add to favorites** from confirmation.

**PizzaWise only records the order in your account.** It does not take payment and does not send the order to the pizzeria.

## Account

**Account** (or **Log in** / **Sign up** in the nav) is where you sign in.

- **Log in** with email and password, or **Sign up** / **Create account**
- When signed in: **Email** is shown as account info, with **Log out**
- **Checkout details:** save **Phone** and an optional **Default delivery address**, then **Save profile** — used to prefill checkout

From the main nav you can also open **Favorites** and **Orders** (**Order history**).

## Favorites

Favorites is a separate flow from ordering. It does not go to location, compare, or checkout.

On **Favorites**, choose **Add pizza**. That opens a dedicated **Pizza Builder** (**Add a favorite**). Build the pizza, then enter a **Favorite name** and **Save favorite**. You return to the favorites list.

**Use** loads that pizza into the order **Build Pizza** flow. **Edit** opens **Edit favorite**: change the name and/or the pizza in the **Pizza Builder** (step pills jump between Size, Crust, Sauce, Toppings, and Ready), then **Save changes**. **Cancel** returns to the list. **Delete** removes it after **Confirm delete**.

## Language

The **Language** control offers **EN** and **HE**. Hebrew uses right-to-left layout for page content. Your choice is remembered in this browser.
